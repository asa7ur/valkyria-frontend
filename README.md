# Valkyria Frontend 🛡️🎸

[![CI](https://github.com/asa7ur/valkyria-frontend/actions/workflows/ci.yml/badge.svg)](https://github.com/asa7ur/valkyria-frontend/actions/workflows/ci.yml)

**Angular 21** web application for **Valkyria**, a music festival platform: lineup, ticket and camping sales, user area and admin panel.

🌐 **Live at [valkyriafest.es](https://valkyriafest.es)** · ⚙️ Backend: [valkyria-backend](https://github.com/asa7ur/valkyria-backend)

> **This is a portfolio project.** The festival is fictional and payments run in Stripe test mode, so no real money is ever charged.

## ✨ Features

* **Landing page**: modular sections (hero, tickets, experience, social, sponsors) with an animated splash screen.
* **Lineup**: artists and stages, per-day schedule and artist detail pages.
* **Purchase flow**: ticket and camping selection, checkout with Stripe and success/cancel handling. Buying as a guest is supported.
* **Accounts**: registration with email confirmation, login, Google sign-in, profile and order history with downloadable PDF tickets.
* **Admin panel**: dashboard plus management of artists, stages, performances, sponsors, ticket and camping types, orders, tickets, campings and users.
* **Internationalization**: Spanish and English with ngx-translate, including the emails and PDFs generated by the backend.
* **Legal pages**: legal notice, privacy policy and cookies, with consent on registration and checkout.

```text

├── core/           # Services, models, guards, interceptors and validators
├── features/
│   ├── admin/      # Admin panel (dashboard and CRUD sections)
│   ├── artists/    # Artist listing and details
│   ├── auth/       # Login, registration, confirmation and OAuth callback
│   ├── home/       # Landing page sections
│   ├── legal/      # Legal notice, privacy and cookies
│   ├── lineup/     # Schedule by day and stage
│   ├── profile/    # User area and order history
│   └── purchase/   # Cart, checkout and payment result
├── layout/         # Header, footer and main layout
└── shared/         # Reusable components, pipes and utilities

public/i18n/        # es.json and en.json
```

Conventions for components, naming and styling are documented in [STYLE_GUIDE.md](STYLE_GUIDE.md).

## 🚀 Getting Started

### Prerequisites

* **Node.js 22 or newer** (CI and the Docker image use 22)
* A running instance of [valkyria-backend](https://github.com/asa7ur/valkyria-backend) on `http://localhost:8080`

### Install and run

```bash
npm install
npm start
```

The app is served at <http://localhost:4200> and reloads on every change.

The backend URL comes from `src/environments/environment.ts`. In production the value is empty on purpose: the app uses relative paths (`/api/...`, `/uploads/...`, `/oauth2/...`) and nginx routes each one, so the same build works on any domain.

## 🧪 Testing

```bash
npm test
```

Unit tests run with Vitest in a jsdom environment.

## 🏗️ Build

```bash
npm run build
```

The output goes to `dist/`. The [`Dockerfile`](Dockerfile) builds the app and serves it with nginx using [`nginx.conf`](nginx.conf).

## 📦 Deployment

Every push and pull request to `develop` or `main` runs the tests on GitHub Actions. Pushing a `vX.Y.Z` tag builds the Docker image and publishes it to **GHCR** as `ghcr.io/asa7ur/valkyria-frontend:X.Y.Z`. The deployment to the production VPS is triggered by the backend release workflow, which deploys both images together after a manual approval.
